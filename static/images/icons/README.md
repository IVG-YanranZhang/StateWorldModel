# Publication resource icons

- `arxiv.svg` and `github.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0. The accompanying license is retained here.
- `huggingface.svg`: the official [Hugging Face logo](https://huggingface.co/front/assets/huggingface_logo-noborder.svg).
- The Demo icon is a small native outline SVG in the page markup.

Icons are hosted locally and are decorative beside the visible resource labels.
